# LifeGame 需求分析文档

## 项目概述

**项目名称**：LifeGame
**项目类型**：AI驱动的剧情选择类文字游戏
**目标平台**：Windows
**技术栈**：C# / WPF / .NET 8
**单局时长**：约10分钟

---

## 核心玩法

玩家通过选择一系列引导选项（性别、年龄、背景、地点、场景等）设定游戏初始条件，AI生成完整的剧情树，玩家根据预生成的选项进行选择，最终达成不同结局。

---

## 功能需求

### 1. 游戏核心流程

| ID | 需求项 | 描述 |
|----|--------|------|
| S1.1 | 关键词选择 | 玩家逐步选择性别、年龄、背景、地点、故事场景等引导选项 |
| S1.2 | 剧情树生成 | 调用AI一次性生成完整剧情树（所有节点、分支、选项、多个结局） |
| S1.3 | 剧情生成完成 | 玩家等待生成完成，显示进度（可接受稍长等待） |
| S1.4 | 剧情浏览 | 玩家根据预生成的选项流畅浏览剧情，无延迟 |
| S1.5 | 选项选择 | 玩家做出选择，系统加载下一节点 |
| S1.6 | 结局触发 | 达到预设时间节点或特定选择触发结局 |
| S1.7 | 游戏回顾 | 显示结局，提供本次游戏所有选择和剧情回顾 |

### 2. 内容管理

| ID | 需求项 | 描述 |
|----|--------|------|
| S2.1 | 保存游戏记录 | 保存游戏所有选择和剧情内容 |
| S2.2 | 读取存档 | 读取已保存的游戏继续游玩 |
| S2.3 | 历史记录 | 查看历史游戏记录和结局达成情况 |
| S2.4 | 多结局探索 | 支持重玩同一套设置，尝试不同选择达成多结局 |
| S2.5 | 手动清理存档 | 玩家可手动删除不需要的存档记录 |

### 3. AI交互接口

| ID | 需求项 | 描述 |
|----|--------|------|
| S3.1 | AI服务商配置 | 支持OpenAI/Azure/本地模型等 |
| S3.2 | API配置 | 配置API密钥和端点 |
| S3.3 | AI参数设置 | 设置温度、最大token等参数 |

### 4. 用户界面

| ID | 需求项 | 描述 |
|----|--------|------|
| S4.1 | 主菜单 | 开始新游戏、继续、设置、历史记录 |
| S4.2 | 引导选择界面 | 逐步选择性别、年龄、背景、地点、场景等 |
| S4.3 | 生成等待界面 | 显示剧情树生成进度 |
| S4.4 | 剧情展示界面 | 滚动文本显示剧情内容 |
| S4.5 | 选项选择界面 | 显示选项供玩家选择 |
| S4.6 | 设置界面 | AI配置、游戏设置 |
| S4.7 | 历史记录界面 | 查看历史游戏记录 |
| S4.8 | 存档管理界面 | 玩家手动清理/删除存档 |

### 5. 游戏设置

| ID | 需求项 | 描述 |
|----|--------|------|
| S5.1 | 游戏时长控制 | 每局约10分钟 |
| S5.2 | 内容长度限制 | AI生成内容的最大长度限制 |
| S5.3 | 剧情复杂度 | 剧情分支的复杂度设置 |

### 6. 扩展功能（后续）

| ID | 需求项 | 描述 |
|----|--------|------|
| S6.1 | 多语言支持 | 支持不同语言 |
| S6.2 | 自定义提示词 | 自定义AI提示词模板 |
| S6.3 | 导出功能 | 导出游戏记录为文本/图片 |
| S6.4 | 成就系统 | 达成特定结局解锁成就 |

## 非功能性需求

- **性能**：生成等待时间不超过60秒
- **兼容性**：支持Windows 10/11及以上系统
- **数据安全**：本地存储，保护用户数据
- **可扩展性**：便于后续添加新功能
- **存储管理**：支持手动清理存档，不自动删除

---

## 备注

- S1.15的引导选择内容可在开发时根据实际情况调整
- AI生成策略：先生成完整剧情树，确保完整性和连贯性
- 所有内容存储在本地SQLite数据库，无需网络连接（除AI调用外）
- 存档清理由玩家手动执行，无自动清理功能
