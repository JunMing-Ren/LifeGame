## 阶段一：AI 集成（核心功能）

### 1.1 AI 服务接口设计

**目标**：支持多种 AI 服务商（OpenAI / Azure / 本地模型）

**任务清单**：
- [ ] 创建 `IAiService` 接口
- [ ] 实现 `OpenAiService`（使用 OpenAI .NET SDK）
- [ ] 实现 `AzureAiService`（Azure OpenAI）
- [ ] 实现 `LocalAiService`（Ollama / LM Studio 等本地模型）
- [ ] 添加 API 错误处理和重试机制
- [ ] 实现流式输出（可选，改善体验）

### 1.2 剧情树生成

**目标**：根据玩家选择的关键词，生成完整剧情树

**任务清单**：
- [ ] 设计剧情树生成的 Prompt 模板
- [ ] 实现剧情树解析（从 JSON 响应构建 StoryTree）
- [ ] 添加生成进度反馈
- [ ] 实现超时处理
- [ ] 添加生成失败重试机制

**Prompt 模板示例结构**：
```
你是一个专业的故事创作者。根据以下设定，生成一个分支剧情游戏：

玩家设定：
- 性别：{gender}
- 年龄：{age}
- 背景：{background}
- 地点：{location}
- 主题：{theme}

要求：
1. 生成约 10 分钟时长的剧情
2. 包含 3-4 个分支点，每个分支有 2-3 个选项
3. 至少生成 2 个不同结局
4. 返回 JSON 格式的剧情树

[JSON Schema...]
```

### 1.3 配置管理

**任务清单**：
- [ ] 实现配置文件的加密存储（API Key 安全）
- [ ] 添加配置验证（测试连接功能）
- [ ] 支持多套配置切换

## 推荐开发顺序

```

  └─ 收尾工作
```
